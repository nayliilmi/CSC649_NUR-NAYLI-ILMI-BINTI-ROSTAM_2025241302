2.2 Users and Scope (A2) 

Users
The main users for the proposed enhancement of the UAPS ePelekat Kenderaan system  are UiTM students and staff from all the branches who use the system to apply for vehicle stickers permission.  
Scope 

In-Scope 
The project focuses on enhancing several main areas of the UAPS ePelekat Kenderaan system interface. These include redesigning the lengthy application form into separate steps by using a tab interface to improve the dashboard by organizing important information and introducing a visual application progress tracker. 
The improvements will also include a clear navigation and consistent interface using Figma. 

II. Out-of-Scope 
The project proposed is not involved in developing the new UAPS ePelekat Kendraan system, altering the existing database or implementing actual application approval and verification processes. 
Payment transactions, backend implementation development and changes to existing sticker policies and processes are also excluded from the project aims.
