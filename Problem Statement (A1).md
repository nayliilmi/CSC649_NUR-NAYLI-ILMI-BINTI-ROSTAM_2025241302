2.0 PROJECT FORMULATION

2.1 Problem Statement (A1)

The UAPS ePelekat Kenderaan system features contains several type sections of information that users need to fill in such as application form, vehicle details, supporting documents and emergency contact information on a continuous page. All this section is presented on one page, requiring users to scroll through several sections which make the application process less organized and convenient to complete. In these situations, users may miss certain required fields, leave information incomplete or invalid supporting documents resulting in application errors. Therefore, a lengthy form structure may create difficulty for users to complete their application form accurately and efficiently.  

Besides, the dashboard of the system provides a sidebar menu for accessing through different services such as checking status, sticker cancellation or replacement. However, the lack of a clear overview of important information such as current application status, registered vehicle details and recent activities on the dashboard features may require users to navigate into different pages to find information they need quickly, making it less convenient and informative. Therefore, an unclear dashboard overview may delay the application process. 

Furthermore, the application status interface mainly presents information in a table format without a clear visual representation count of application progress. This may make it difficult for users to understand where exactly their current application stage and identify the next required action. Therefore, the improvement aim will be made to provide a more organized, accessible and user-friendly experience for UiTM users. 

Overall, this project proposed to enhance the existing UAPS ePelekat Kenderaan interface by introducing a Rule-Based Expert System for application form validation including in improving the design for application progress and dashboard features. These improvements aim to provide a convenient, organized and user-friendly interface for all UiTM student and staff accessibility.
