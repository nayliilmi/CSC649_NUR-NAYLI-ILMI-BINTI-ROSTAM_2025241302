4.0 SPECIALIZED TECHNOLOGY AND FUNDAMENTAL CONCEPTS

4.1 Fundamental Concepts (C1)

4.1.1 Introduction to Rule-Based Expert System

A Rule-Based Expert System is one of a type of Artificial Intelligence (AI) system that uses predefined logic rules and knowledge to make decisions and solve the problems within a specific domain. It used to represent knowledge of using IF-THEN statements where the IF defines a logical condition while THEN acts to determine the conclusion when the conditions are met. The system uses a knowledge base to store predefined rules and an inference engine to evaluate the conditions, determine and evaluate the corresponding action.
A Rule-Based Expert System relies and follows rules that have been defined based on domain knowledge and specific requirements which allows the system to produce consistent decisions-making whenever the same conditions are applied. Furthermore, this approach has been used in various applications that require logical reasoning and decision-making problems based on the predefined conditions. 

4.1.2 Key Concepts of Rule-Based Expert System

Below are the several key concepts that form the Rule-Based Expert System: 

1. Knowledge Base 

Knowledge Base is the specialized database that stores all the human expertise containing the facts, theories and rules of thumb that a human expertise uses to solve a specific problem. It also contains the information that the system uses for evaluating each condition and determining the suitability of actions. 

2. Inference Engine

An inference engine acts as the reasoning of an expert system that evaluates available information and compares it with the rules defined in the knowledge base. It determines which conditions match the rules and carries out the corresponding actions to produce the results.
 
3. Working Memory 

Working memory, also referred to as  a Fact Base, stores the facts and information 
that are related to the current situation being evaluated by the system, then used by the inference engine to make comparisons to the condition in the knowledge base. 

4. Production Rules (IF-THEN Rules) 

Production rules are the basic elements that are used to represent knowledge and decision-making conditions which each rule consists of two main parts, IF conditions work to specify the situation while THEN is the action that determines the response when the condition is true.  

4.1.3 How Rule-Based Expert System Works

A Rule-Based Expert System works by collecting the information, comparing the facts with predefined rules and producing a response based on the required conditions. The process starts when the user provides the information to the system. The information is stored as facts in the working memory and the inference engine will evaluate the facts against the rules in the knowledge base. When the condition meets the rules, the system activates the corresponding action and produces a result.
