3.3 Users Stories (B3)

User Story 1: Multi-step Application Form (FR2,FR3,FR4,FR5,FR6,FR7,FR9)

As a UiTM user, I want the vehicle sticker application form to be divided into separate process forms so that I can complete the application more easily and systematically without having any missing required fields.

Acceptance Criteria:

1. The system shall display separate tabs by step for applicant information, vehicle information, supporting documents and emergency information.
2. The system shall display a progress indicator that shows the current application step.
3. The system shall highlight the missing required field before moving to the next tabs.
4. The system validates uploaded supporting documents based on predefined criteria rules including the required documents and file formats.
5. The system shall display a trigger for a proper notification to inform users if the required field is missing or invalid documents.
6. The system shall allow users to proceed to the next application process only when all required application information and supporting documents meet the rules.
7. The system shall allow users to review their application details before submission.

User Story 2: Multi-step Application Form (FR1)

As a UiTM user, I want an organized and informative dashboard so that I can easily access important application information faster.

Acceptance Criteria:

1. The dashboard shall display the current application status and registered vehicle information.
2. The dashboard shall provide a quick navigation button to allow users access different pages more easily.
3. The dashboard shall display recent activities and relevant information.

User Story 3: Multi-step Application Form (FR8)

As a UiTM user, I want to track my application using a visual progress tracker rather than table format so that I can understand my current application status and identify next required actions.

Acceptance Criteria:

1. The system shall display the application stages using progress indicators.
2. The tracker shall display the current application status.
3. The system shall display the latest application update information when the process is available.
