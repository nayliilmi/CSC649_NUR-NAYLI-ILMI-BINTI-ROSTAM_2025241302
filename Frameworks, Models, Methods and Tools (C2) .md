4.2 Frameworks, Models, Methods and Tools (C2) 

There are several frameworks, methods and models that are associated with Rule-Based Expert Systems. 

1. Rule Based System Framework 

A Rule-Based System Framework contains three main components which include working memory, rule base and inference engine. Working memory acts to store facts and information about current problems stated while the rule base consists of predefined IF-THEN rules. Then the inference engine will evaluate the available facts against the rules to determine the accurate action and produce the results. This framework will separate the information being processed from the rule to make decision-making. 

2. Production Rule Method (IF-THEN Rule) 

Production Rule system method used to represent knowledge through IF-THEN rule statements. Each rule contains two main parts which IF works as it specifies a situation that must meet the rules while THEN action determines the response when the condition is met. This method is used for defining decision-masking conditions and ensuring accurate actions produced. In the proposed UAPS system, this method will be used to evaluate the document validation conditions.  

3. Forward Chaining Method

Forward chaining is a method that starts with available facts and evaluates the facts against predefined rules to produce a conclusion for the actions. Then, the inference engine checks whether the condition meets the rule and activates the corresponding action to generate the results. This method is used when decisions need to be made based on information given by the users.  

4. Production System Models
The Models is a problem solving model that uses predefined rules to analyze available information facts and produce the appropriate conclusions for each action. It contains a long-term memory which stores the production rules, short-term memory which stores the facts related to the current problem and the reason process that applies the rules to the available facts. These models explain how knowledge and problems with specific information can work together to conclude decision-making.
