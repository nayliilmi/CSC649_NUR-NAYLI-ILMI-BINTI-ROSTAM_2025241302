3.2 Non-Functional Requirements (B2)

The non-functional requirements describe the expected quality and usability of the proposed interface.

| ID | TYPE | NON-FUNCTIONAL REQUIREMENT |
|---|---|---|
| NFR1 | Usability | The system shall allow users to complete the application process with minimal confusion. |
| NFR2 | Reability | The system shall display consistent validation messages for all validation features in application form. |
| NFR3 | Accessibility | The interface of the system shall provide clear labels and sufficient colour contrast to support readability. |
| NFR4 | Consistency | The interface of the system shall maintain consistent navigation elements for all pages. |
| NFR5 | Efficiency | The dashboard shall allow users to access each module pages more easily and faster. |
